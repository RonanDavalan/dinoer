# Dinoer — Field feedback

A log of the frictions met while using Dinoer for real work, by a model or by
its operator. Each entry records what happened and what resolved it, so that
the next run does not have to rediscover it.

No entry yet.

---

## Adding an entry

Append a dated section, newest last:

- **Date and version** — the day of the run and the output of
  `/opt/dinoer/venv/bin/python3 /opt/dinoer/shot.py --version`.
- **Friction** — what happened, with the exact command and the part of its
  output that shows the problem.
- **Cause** — the mechanism, once established. Leave it out rather than guess.
- **Resolution** — what fixed it or how to avoid it, with the commit or the
  documentation section that carries the fix, when there is one.

Only frictions met while running Dinoer belong here. No private hostname,
address or credential ever appears in an entry.
